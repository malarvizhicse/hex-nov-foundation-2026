Assignment 2: Binary Search Tree
Given insertion order: 50, 30, 70, 20, 40, 60, 80, 65.
1. Preorder Traversal
- Rule: Root → Left → Right
- Answer: 50, 30, 20, 40, 70, 60, 65, 80
2. Inorder Traversal
- Rule: Left → Root → Right
- Answer: 20, 30, 40, 50, 60, 65, 70, 80
3. Postorder Traversal
- Rule: Left → Right → Root
- Answer: 20, 40, 30, 65, 60, 80, 70, 50
4. Which traversal gives the numbers in sorted order? Why?
Inorder traversal gives the numbers in sorted ascending order because in a Binary Search Tree, smaller values are stored on the left and larger values are stored on the right.
